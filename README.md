# CourseFlow — AI-Powered Course Creation Platform

[![Vercel Deploy](https://img.shields.io/badge/Live-Demo-155DFC?color=blue&logo=vercel&logoColor=white)](https://www.courseflow.tech/)
[![License](https://img.shields.io/badge/License-MIT-crimson.svg)](#)

**CourseFlow** is a full-stack AI-powered platform that enables users to **design, structure, and generate complete courses effortlessly**.

From selecting a category to generating a full course layout with chapters, duration, and difficulty — CourseFlow streamlines the entire course creation workflow using AI.

---

## 🚀 Features

- 🧩 **Step-by-Step Course Builder** – Guided flow for creating structured courses  
- 🤖 **AI Course Layout Generation** – Automatically generates chapters, descriptions & duration  
- 🗂️ **Multiple Categories** – Coding, Health, Creative, and more  
- ⚙️ **Custom Course Options** – Difficulty, duration, chapters, and video preference  
- 🔐 **Authentication with Clerk** – Secure login & user management  
- 🔗 **Shareable Course Links** – Access courses via unique URLs  
- 📱 **Fully Responsive UI** – Optimized for mobile, tablet, and desktop  
- ⏳ **Loading & Skeleton States** – Smooth user experience

## ⚙️ How It Works

1. Select a course category  
2. Enter topic and description  
3. Configure options (difficulty, duration, chapters, video)  
4. Generate course layout using AI  
5. Save, view, and share your course
